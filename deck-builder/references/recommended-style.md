# 系統推薦風格

用於公司樣板不合的場合：主題和公共安全毫無關係，或這是一份內部快速簡報，樣板那些公共安全
底圖只是雜訊。

由空白 16:9 簡報建立，所以沒有可繼承的 master——`build_deck.py` 自己畫每一頁。它保留企業藍，
所以看起來仍是同一個組織，但版面組小而密實。

## 色票

主色與公司樣板相同，所以兩種風格混用也不衝突。

| 用途 | Hex |
|---|---|
| 主色 | `#0d63ba` |
| 主色深 | `#0b539d` |
| 內文 | `#13182c` |
| 次要文字 | `#5a5f6e` |
| 分隔線 | `#d8d8d8` |
| 面板填色 | `#f4f6f9` |
| 背景 | `#ffffff` |
| 警示 | `#ff737f` |

`#5a5f6e` 在白底是 6.4:1——次要文字用它是安全的。**不要**在這裡改用公司樣板的 `#b4b4b4`；
它在內文尺寸下不符 AA。

## 字級

英文用 **Segoe UI**（`a:latin`）＋中文用**微軟正黑體／Microsoft JhengHei**（`a:ea`）。
兩者都寫在每一個 run 上。字級刻意很少。

| 用途 | 字級 | 字重 | 顏色 |
|---|---|---|---|
| 封面標題 | 40 pt | bold | `#13182c` |
| 封面副標 | 18 pt | regular | `#5a5f6e` |
| 段落分隔 | 32 pt | bold | `#0d63ba` |
| 頁面標題 | 28 pt | bold | `#13182c` |
| 內文／要點 | 18 pt | regular | `#13182c` |
| 第二層要點 | 16 pt | regular | `#5a5f6e` |
| 表頭 | 14 pt | bold | `#0d63ba` 上的白字 |
| 表格內容 | 14 pt | regular | `#13182c` |
| 圖說／來源 | 12 pt | regular | `#5a5f6e` |

內文 18 pt，段距 12 pt。中文需要較鬆的行距——不要為了多塞內容而壓縮它；砍內容。

## 格線（吋，基於 13.333 × 7.5）

- 邊界：左右 **0.90**、上 **0.55**、下 **0.70**
- 內容寬度：**11.53**
- 標題：`(0.90, 0.55, 11.53, 0.90)`，下方 y = 1.52 有一條 2.2 吋 × 3 pt 的 `#0d63ba` 線
- 內文區塊：`(0.90, 1.75, 11.53, 4.90)`
- 雙欄切分：左 `(0.90, 1.75, 5.55, 4.90)`、右 `(6.88, 1.75, 5.55, 4.90)`
- 頁碼：右下 `(12.10, 6.90)`，11 pt `#5a5f6e`

y = 6.80 以下不放任何東西。沒有元素碰到邊界。

## 版面

| 名稱 | 內容 |
|---|---|
| `title` | 置中的封面標題＋副標，中間一條藍線 |
| `section` | 大的藍色段落標籤，垂直置中，上方一條細線 |
| `content` | 標題＋線＋要點或敘述 |
| `two-column` | 標題＋兩個內文區塊 |
| `image-right` | 標題＋左側要點，右側圖片 |
| `image-full` | 標題＋一張置中大圖，可選圖說 |
| `table` | 標題＋表格，藍色表頭，`#f4f6f9` 斑馬紋 |
| `quote` | 置中的大字陳述，32 pt，附出處——用於單一關鍵數字或主張 |
| `closing` | 那個請求，加上負責人與日期 |

在 spec JSON 裡用同樣的 `layout` 名稱。除此之外 spec 格式與公司風格完全相同，所以同一份大綱
可以在兩種風格間重建，不必改寫內容。

## 什麼時候該選它而不是公司樣板

| 情境 | 風格 |
|---|---|
| 面對客戶、標案、合作夥伴 | 公司樣板 |
| 主題是公共安全產品線 | 公司樣板 |
| 內部進度、回顧、設計審核 | 推薦風格 |
| 主題與產品線無關 | 推薦風格 |
| 簡報會被列印或縮小輸出成 PDF | 推薦風格（更密實、對比更高） |
| 使用者有自己的品牌規範 | 問他們要樣板——選項 3 |
