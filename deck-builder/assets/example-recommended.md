## chart

**標題** 對比度全部低於 AA 的 4.5:1

**圖表**

```json
{
  "form": "bar",
  "categories": ["說明文字", "次要標籤", "停用狀態", "頁尾", "佔位文字"],
  "series": [{"name": "對比度", "values": [1.90, 2.40, 2.80, 3.10, 4.10]}],
  "colors": "sequential",
  "number_format": "0.00\":1\"",
  "max_scale": 5,
  "label_points": [0, 4]
}
```

**備註** 橫向長條，因為類別名字長。序數色階：淺到深就是從最差到最接近合格。只標首末，中間三個讀格線就夠。
