# 會議記錄小幫手（meeting-minutes）

把會議或教學的錄音交給 AI，它會寫出一份可以直接轉貼給同事的會議記錄。

**Mac 和 Windows 都能用。** AI 工具可以用 Cursor、VS Code、Codex 或 Claude Code。

---

## 它能幫你做什麼

開完會，你只要把錄音交給 AI，就會拿到：

- **一份會議記錄**：總結、待辦（寫清楚誰負責）、決議、還沒決定的事、討論細節。如果是教學或交接，會改成操作步驟和注意事項。
- **一份逐字稿**：誰在什麼時間說了什麼，可以回頭查。
- **一張「聽不清楚的地方」的表**：AI 最沒把握的幾十句，**可以不填**。填了的話，下次大家轉錄都會更準。

有附上簡報、PDF、Excel 的話，AI 會拿來對照，把專有名詞寫對，並標出內容出自第幾頁。

---

## 怎麼開始


| 步驟               | 看哪份                                                      |
| ---------------- | -------------------------------------------------------- |
| **1. 安裝**（只要做一次） | [1-install.md](1-install.md)。先克隆倉庫，再請 AI 照著裝。安裝時會自己下載約 1.6GB 的語音模型，倉庫裡沒有這個檔。 |
| **2. 每次開完會**     | [2-usage.md](2-usage.md)。在 AI 對話框輸入 `/minutes`，附上錄音和參加者名單。 |


每次交給 AI 的東西很簡單：

```
/minutes
音檔：~/Desktop/會議記錄/audio/2026-09-11-設計評審.m4a
投影片：~/Desktop/設計評審.pptx
參加者 3 位：Joyie（主持人）、Zoe、Allen
```

---



## ⚠️ 使用前請先知道

**錄音不會上傳，但文字會。** 錄音檔會留在你的電腦，在本機轉成文字。但轉出來的逐字稿、螢幕錄影的截圖，會交給 AI 工具讀，AI 才寫得出會議記錄。

所以這些會議**不要用**：

- 人事、薪資
- 法務
- 未公開的財務資訊

**詞彙表是全隊共用的。** 大家校對過的人名、專案名、客戶名會累積在同一份詞彙表，並透過 GitHub 分享給同事。所以這個工具的 GitHub 倉庫只開放給團隊成員。

## 資料夾裡的其他檔案

同事不需要打開這些檔案，照上面兩份說明做就好。


| 檔案                    | 用途                   |
| --------------------- | -------------------- |
| `maintenance.md`             | 給要修改這個工具的人：設計理由、實測數字 |
| `INSTRUCTIONS.md`     | 給 AI 讀的整理規則          |
| `install.sh`          | Mac 安裝程式             |
| `install.cmd`         | Windows 安裝程式（雙擊執行） |
| `templates/`          | 會議記錄的兩種格式範本          |
| `config/glossary.txt` | 全隊共用的詞彙表             |
